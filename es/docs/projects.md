## Información pendiente por producto

Para cada repositorio de producto (excepto este catálogo), debe añadirse lo siguiente en el repositorio del propio producto antes de que este catálogo pueda describirlo como utilizable:

- Un `README.md` que explique qué hace el producto, para quién y cuál es su nivel de madurez actual.
- Un archivo de licencia.
- Datos verificados de funcionalidad y tecnología, para que este catálogo pueda sustituir las entradas "pendiente" de arriba.
- Instrucciones de instalación o despliegue, o una declaración explícita de que el producto es un servicio alojado y no puede autoalojarse.
- Al menos un release, o una declaración explícita de cómo se consume el producto antes de su primer release.

Cuando un producto añada esta información, actualiza su sección aquí y la tabla resumen del inicio de este archivo. Mantén el catálogo central breve: enlaza con la documentación del producto en lugar de copiarla.
